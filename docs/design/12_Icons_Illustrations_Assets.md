# 12 --- Icons, Illustrations & Assets

## Goals

Maintain a consistent visual language.

### Icons

-   Lucide Heroicons compatible
-   20/24px grid
-   Stroke based

### Illustrations

-   Minimal
-   Technical
-   Flat gradients

### Images

-   WebP preferred
-   Responsive
-   Optimized

### Logos

Store separately with light/dark variants.

### File Naming

feature-name_variant.ext
