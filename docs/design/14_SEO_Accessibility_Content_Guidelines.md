# 14 --- SEO, Accessibility & Content Guidelines

## SEO

-   Semantic HTML
-   Meta title/description
-   Open Graph
-   Canonical URLs
-   Sitemap

## Accessibility

-   WCAG AA
-   Keyboard navigation
-   Focus states
-   Alt text
-   ARIA where required

## Content

-   Clear headings
-   Short paragraphs
-   Consistent terminology
-   Descriptive links
