# 11 --- Animations & Microinteractions

## Purpose

Define consistent motion across the portfolio.

### Principles

-   Fast (150--300ms)
-   Purposeful
-   Accessible
-   Consistent

### Motion

-   Fade
-   Slide
-   Scale
-   Stagger lists

### Components

Buttons, cards, dialogs, drawers, menus, page transitions, skeletons.

### Hover

-   Elevation
-   Border highlight
-   Shadow
-   Subtle scale (≤1.02)

### Loading

-   Skeletons
-   Progress indicators

### Accessibility

Respect prefers-reduced-motion.

### Deferred

Parallax, 3D effects, advanced motion.
